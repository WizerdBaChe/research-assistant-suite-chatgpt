# Security

Do not report credentials, private documents, tokens, cookies, or unpublished research in
a public issue. For a suspected security or privacy problem, use GitHub's private security
advisory flow for this repository when available. If that flow is unavailable, open an
issue containing only a sanitized description and write security-sensitive in the title;
do not include the secret or private payload.

The package intentionally excludes credentials, private research corpora, source-agent
hooks, local services, runtime state, and workstation paths. Report any violation of that
boundary with the smallest public-safe reproduction.
