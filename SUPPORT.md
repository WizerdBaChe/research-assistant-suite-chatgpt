# Support

For a reproducible bug report, open a GitHub issue:

<https://github.com/WizerdBaChe/research-assistant-suite-chatgpt/issues>

Include the plugin version, host surface (ChatGPT Web, ChatGPT workspace, Codex desktop,
or Codex CLI), the smallest prompt or fixture that reproduces the issue, and the observed
versus expected routing or contract behavior. Remove credentials, unpublished research,
access tokens, and personal information before posting.

For a security or privacy concern, follow [SECURITY.md](SECURITY.md) and avoid putting
secrets in a public issue.
